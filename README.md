### Featured Projects

#### [FLAME – Small Language Model Pre-training Framework](https://github.com/RTensorLabs/FLAME)
`Rust` `Candle` `CUDA` `PyTorch` `NVIDIA DGX Spark`
- Built a from-scratch training framework in **Rust** with a **LLaMA-style Transformer** (RMSNorm, RoPE, SwiGLU) and a custom 8,192-token byte-level BPE tokenizer, matching PyTorch with a max logit difference of 4.8e-7.

- Developed an **OCR-to-geocoding module** with PaddleOCR that reads unstructured shipping labels and resolves 98.5% of addresses for route planning.

#### [BrainBolt – Multimodal RAG System](https://github.com/rohxn08/BrainBolt) · [Live Demo](https://rohxn08-brain-bolt.hf.space/)

- Served the pipeline through an asynchronous **FastAPI** backend handling ingestion, retrieval and generation, with time to first token under 5s for text and PDF inputs.
